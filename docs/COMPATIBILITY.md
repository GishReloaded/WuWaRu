## Что проверяется автоматически

- Автономные тесты: кэш, форматирование, варианты шаблонов, повторные запросы, сохранение списка подключённых ресурсов, чистая конфигурация и публичная упаковка.
- При извлечении: целостность SQLite баз.
- При сборке: целостность изменённых баз и SHA-1 каждой базы после независимой распаковки FModelCLI.
- При установке: версия ресурсов, подпись исходных пакетов, SHA-1 собственного PAK и отсутствие запущенного клиента.

Дополнительная интеграционная проверка после `main.py build`:

```powershell
py -3.10 verify_package.py
```

Она сравнивает все записи, схемы и нетекстовые поля, а также структуру форматирования изменённых строк. Требуются локальные исходные базы и распакованный пакет, которые появляются при извлечении и сборке.

## Что проверяется вручную

Загрузка пакета клиентом и видимый русский текст проверяются отдельно. Успех тестов GitHub Actions подтверждает автономные проверки и сборку EXE; Actions не запускает игру и не подтверждает совместимость нового клиента.

## После обновления

1. Заверши официальное обновление игры.
2. Обнови публичные ключи, если извлечение не работает.
3. Запусти извлечение и сборку через WuwaRu: одинаковые исходные строки сохраняют кэш.
4. Установи пакет при закрытом клиенте.
5. Проверь загрузку, меню, задания и диалог.

Для отчёта об ошибке достаточно версии клиента и ресурсов, шагов воспроизведения и короткого фрагмента соответствующего журнала. Личные данные не нужны.
