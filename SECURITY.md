# Сообщения о проблемах безопасности

В открытых Issues не публикуй API-ключи, учётные данные, полный кэш или личные журналы.

Если в разделе [Security](https://github.com/GishReloaded/WuWaRu/security) доступна кнопка **Report a vulnerability**, используй её для приватного отчёта. Если приватная отправка недоступна, создай Issue только с общим описанием и просьбой о закрытом канале связи; детали эксплуатации и чувствительные данные сохрани до ответа сопровождающего.

Укажи версию WuwaRu, затронутый компонент, условия воспроизведения и ожидаемое влияние. Приложение отправляет строки локализации выбранному сервису перевода; ключ собственного API берётся из переменной среды. Внешний экстрактор загружается из закреплённого релиза с проверкой SHA-256.

Текущий поддерживаемый выпуск — ветка 0.1.x. Сроки ответа не гарантируются.
